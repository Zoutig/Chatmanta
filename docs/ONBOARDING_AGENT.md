# Onboarding voor Claude Code (agent)

Je hoeft dit bestand niet apart te lezen: `AGENTS.md` (via `CLAUDE.md`) wordt bij elke sessie
automatisch geladen en bevat alles wat je bij de start nodig hebt — wat ChatManta is, de kaart
V0/V1/site, de hard rules, wanneer je zelf handelt vs eerst vraagt, werkwijze en commando's.

Daarna, per onderwerp:

- **Valkuilen per gebied** — `docs/AGENT_LANDMIJNEN.md` (lees de sectie van het gebied waar je in werkt).
- **Scope en principes** — `docs/V2_SCOPE_EN_PRINCIPES.md`.
- **V1-beslissingen en launch-stand** — `docs/V1_STATUS_EN_PLAN.md`, `docs/V1_LAUNCH_TODO.md`.
- **Waar het werk gebleven was** — de nieuwste file in `docs/handoffs/`.

Onboarding voor mensen: `docs/ONBOARDING.md`.
