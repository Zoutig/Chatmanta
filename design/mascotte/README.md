# Mascotte-bronmateriaal

Bronbeelden van de ChatManta-mascotte. Uitleg, gebruik en ontwerpregels: [`docs/site/MASCOTTE.md`](../../docs/site/MASCOTTE.md).

- `bron/` — face-rig (lichaam zonder gezicht, ogen, oogleden, monden, `manifest.json`)
- `stills/` — transparante stills per expressie (gegenereerd: `npm run mascotte:assets -- --stills`)
- `referentie/` — overzichtsplaten
